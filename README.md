# Greenlight Market

A marketplace where indie developers sell finished games, playable prototypes and game ideas to other developers, studios and investors.

- Static site: `index.html`, `styles.css`, `app.js`, `config.js` (served by GitHub Pages)
- Backend: Supabase (Postgres with row-level security, Auth, Storage, Realtime). Database setup lives in `supabase/schema.sql`.
